# fonts

All SIL Open Font License 1.1 (license files next to each font):

| font | used for | full version |
| --- | --- | --- |
| Dela Gothic One | titles, the ticket, LED sign | https://fonts.google.com/specimen/Dela+Gothic+One |
| DotGothic16 | printed ticket fields, LCDs | https://fonts.google.com/specimen/DotGothic16 |
| Yusei Magic | marker handwriting (setlist, tapes) | https://fonts.google.com/specimen/Yusei+Magic |
| Space Mono | labels | https://fonts.google.com/specimen/Space+Mono |

The three Japanese fonts are trimmed (Latin, symbols, all kana, a few hundred
common kanji) to keep the repo light. If the build prints `missing glyphs`, see
the note at the top of `subset.py`.
